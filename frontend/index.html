About CDVH Platform

Disaster Management.
Elevated by AI.

During disasters, organising help is extremely difficult — information is scattered and finding volunteers with the right skills in real-time is a major challenge. CDVH solves this by integrating Machine Learning for intelligent task matching and Natural Language Processing to instantly understand emergency messages.

ML Volunteer Matching

Scikit-learn algorithms match profiles by distance, skills, and urgency level in real-time.

RAG AI Chatbot

FAISS vector search provides grounded answers from official Kerala disaster guidelines.

DL Intent Detection

LSTM + Softmax model classifies emergency intents automatically from distress messages.

Secure FastAPI Backend

JWT authentication, PostgreSQL, and role-based access control for all user types.

Our platform uses TensorFlow and Keras with an LSTM architecture to process incoming distress messages. The NLP module performs tokenisation, embedding, and LSTM processing to automatically classify intents and extract required volunteer skills.
